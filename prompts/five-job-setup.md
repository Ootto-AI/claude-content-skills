# The five-job Instagram setup: all the prompts

Five jobs, one prompt each, all run inside the Claude desktop app.
Paste them in order the first time, then reuse them every time you make a reel.

## The setup

1. Open the Claude desktop app and go to Settings, then Connectors, then Add custom connector.
2. Name it Ootto and paste `https://mcp.ootto.ai/mcp`, then connect.
3. Sign in at ootto.ai and connect your Instagram (a Business or Creator account).
4. Tell Claude about your brand once, so every prompt below can use it: "Read my website [URL] and my last 20 reels, and build my brand brain: niche, voice, audience, colours, what to always do and never do."

Replace everything in [brackets] before you send a prompt.

## Job 1: The researcher

```
Research my niche on Instagram: [your niche].
Find the reels that went viral in the last 30 days, rank them by views and give me the top 10 with the hook, the format and why it worked.
Then tell me the 3 I should make next, and why.
I only want the pattern. Never copy anyone's words, visuals or caption.
```

## Job 2: The writer

```
Write a 40 second reel script on [topic] in my voice. Read my brand brain first.
Use the strongest hook pattern from the research above, in my own words.
Front load the hook: the proof or the result lands in the first 2 seconds. One idea per line.
When I correct you, save the correction as a rule and follow that rule in every script from now on.
At the end, list which rules you used.
```

## Job 3: The editor

```
Turn this script into a reel.
A new visual on every line, on-screen captions, voiceover and sound, in my colours.
Everything on screen moves. Keep text inside the Instagram safe zones.
Show me a preview first and wait for my notes before you finish it.
```

## Job 4: The poster

```
Write the caption and show me the reel and the caption together.
Keyword rich, first line is a hook, 5 hashtags at most.
Do not post until I say yes.
When I say yes, post it to my Instagram and send me the link.
```

## Job 5: The A/B tester

```
Make 5 versions of this reel.
Same body, 5 different hooks in the first 3 seconds. Each hook takes a different angle: result, contrarian, question, mistake, story.
Give me every file and a caption for each, labelled A to E.
I will post each one as a trial reel by switching on Trial in the Instagram app, so it shows to people who don't follow me yet.
After 72 hours, pull the views, watch time, shares and saves for each one, rank them and name the winner.
Tell me which one to share to my main page, and save the winning hook pattern as a rule for the writer.
```

## How to run it every week

Run jobs 1 to 4 for each new idea, and run job 5 on anything you believe in.
A winner goes to your main page, and its hook pattern goes back to the writer.
That loop is the whole system.
