# Community Engagement Plan
Design a useful participation plan, not automated spam.

## Instructions
`Build a weekly human-led engagement plan for these community spaces and this goal. Define where to participate, the useful contribution to make, boundaries, escalation rules, and how to log repeated demand. Never automate unsolicited replies.`
